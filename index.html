Project Overview

I. Project Description

Each group will design and develop a Microsoft Excel workbook for a specific business operation or record management process. The workbook must demonstrate how Excel can organize business data, perform calculations, analyze records, and present meaningful information for decision-making.

The project must apply the concepts discussed in class, including spreadsheet operations, formulas, arithmetic operators, comparison and logical operators, text concatenation, cell references, functions, sorting, filtering, and spreadsheet formatting.

The output must be functional, accurate, organized, and relevant to the assigned business scenario.

C. Required Excel Topics

Your workbook must apply the following concepts discussed in class.

1. Basic Operations

Enter, edit, copy, and move data; insert rows or columns; adjust widths and heights; organize worksheet tabs.

2. Arithmetic Operators

+ − * / %

Apply addition, subtraction, multiplication, division, and percentage calculations.

3. Comparison Operators

= <> > < >= <=

Compare values, produce TRUE or FALSE results, or establish conditions in formulas.

4. Text Concatenation (&)

Combine text values, such as first and last names, customer details, or product codes and names.

5. Required Excel Functions

SUM() AVERAGE() MAX() MIN() COUNT() COUNTIF() IF()

Use SUM for totals, AVERAGE for averages, MAX and MIN for extreme values, COUNT for numeric entries, COUNTIF for conditional counts, and IF for conditional results.

6. Cell References

Use cell references in formulas, copy formulas across rows, and observe how results change when inputs change.

7. Sorting and Filtering

Sort records and filter data using relevant conditions. Use FILTER() where supported by your Excel version.

8. Formatting and Presentation

Apply appropriate number formats, borders, headings, alignment, and consistent formatting.
